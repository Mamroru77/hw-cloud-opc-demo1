# 云脉 — 大赛评审标准对标分析

> 来源：大赛评分标准以及使用华为云码道加分细则.md、README.md、.agents/spec.md

## 创新应用（25分）

### 差异化创新
- **转化医学全链路Agent**：行业首创"学术论文→参数提取→临床适配→商业方案"端到端多智能体工作站，覆盖4大转化医学细分领域
- **盘古真实API直连**：非DeepSeek转发，is_proxy=False直连华为云，实现华为自研大模型的深度融合
- **星闪协议模拟**：INearLinkAdapter接口与真实SDK API签名对齐，未来可零修改替换为真实星闪硬件

### 开创新产品类别
- 填补"转化医学AI辅助决策平台"空白，将传统需要多学科团队协作的医学成果转化流程，压缩为OPC一人可完成的工作流
- 区别于通用医学AI，聚焦"从实验室到临床"的特定转化阶段

## 技术架构（25分）

### 技术融合度
- AI+鸿蒙+NPU+RAG深度融合：大模型推理 + 鸿蒙端云协同 + 端侧隐私脱敏 + 知识库检索增强
- 多模型降级链：5大模型自动切换，保障服务连续性
- 双模降级系统：后端不可达时自动切换至高保真前端Mock模式

### OPC架构适配性
- 一人全栈开发：React 19前端 + FastAPI后端 + Docker部署，全链路独立交付
- 轻量化架构：无需Kubernetes运维知识，docker-compose一键启动
- 27个pytest自动化测试，保障代码质量

### 端边云协同架构
- **鸿蒙端侧**：HarmonyDrawer设备发现/协同 + HarmonyWidget卡片预览 + NPU本地脱敏（模拟实现，已标注）
- **华为云后端**：CCE容器部署 + SWR镜像服务 + CodeArts Pipeline CI/CD
- **跨终端推流**：星闪协议模拟层实现端云数据双向同步

### 架构品质
- 双模降级保障99.5%可用性（在线）/ 100%可用性（离线Mock）
- 4类安全检查规则 + 高危门禁阻断部署
- 健康检查 + 自动回滚机制

## 功能完备（25分）

### 核心功能逻辑顺畅性
- 4大领域全链路覆盖：devices/drugs/ai/surgical各有专属参数+图表+文档模板
- 论文上传→领域自动识别→参数提取→设备匹配→文档生成，流程闭环
- 智能论文领域校验：非相关文件自动拒绝导入

### 界面设计与交互专业性
- Glassmorphic + Neumorphic混合美学，医疗科技感
- 4类自适应ECharts图表：PK代谢曲线/ROC诊断曲线/学习曲线/雷达图
- 拖拽上传 + 实时参数热更新 + System Prompt交互编辑器
- 8轮UI视觉迭代优化至鸿蒙原生级别

## 商业前景（25分）

### 市场与受众定位
- 4大赛道：医疗器械/创新药物/医疗AI/创新术式，对应苏州工业园区生物医药支柱产业

### 投资回报预期
- 降低转化医学评估成本：AI辅助替代多学科团队初筛，人力成本降低80%+
- 缩短转化评估周期：从数周压缩至数分钟

### 社会价值
- 加速"从实验室到临床"的医学成果转化，惠及患者
- 覆盖精准医疗、靶向药物、手术机器人等前沿方向

### 市场推广可行性
- 双模降级系统支持离线Demo路演，降低推广门槛
- Docker一键部署，降低客户试用成本
- 鸿蒙生态原生适配，覆盖华为终端用户群
