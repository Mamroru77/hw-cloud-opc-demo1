**架构要点**：
- 前端5大组件：ModelSelector / KnowledgeManager / HarmonyDrawer / CICDStatusPanel / NpuSandboxPanel
- 后端4大服务：LLM Adapters（5模型） / Knowledge Service（ChromaDB+RAG） / Harmony WS（星闪模拟） / CICD Service（Pipeline+DevLog+Insight）
- 状态管理：Zustand Stores（harmony/model/knowledge三模块）
- 降级链：pangu → deepseek → openai → glm → gemini

## CI/CD流水线

### 流水线阶段
1. **前端构建**：npm install + npm run build
2. **后端测试**：pip install + pytest（27个测试用例）
3. **安全检查**：CodeArts安全扫描（高危阻断部署）
4. **构建Docker镜像**：前后端分别构建
5. **推送镜像至SWR**：登录华为云容器镜像服务并推送
6. **部署到CCE**：华为云容器引擎部署（2副本+健康检查）

### 健康检查与回滚
- readinessProbe：HTTP /health，初始延迟10s，周期10s，3次失败阈值
- livenessProbe：HTTP /health，初始延迟15s，周期20s，3次失败阈值
- 自动回滚：6次健康检查失败后触发 kubectl rollout undo 自动回滚

## 安全检查规则

| 规则ID | 名称 | 严重级别 | 描述 | 动作 |
|--------|------|----------|------|------|
| SQL_INJECTION | SQL注入检测 | high | 检测潜在SQL注入漏洞 | 阻断 |
| XSS_DETECTION | XSS跨站脚本检测 | high | 检测XSS攻击向量 | 阻断 |
| SENSITIVE_DATA_LEAK | 敏感信息泄露检测 | high | 检测明文密码/密钥泄露 | 阻断 |
| HARDCODED_KEY | 硬编码密钥检测 | high | 检测硬编码的密钥和凭证 | 阻断 |

**高危门禁策略**：fail_on_high=true，高危漏洞直接阻断部署
