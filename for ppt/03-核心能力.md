# 云脉 — 核心能力详述

## 五大技术要求实现概要

### 码道平台特色能力联动
- CI/CD流水线：6阶段自动化（前端构建→后端测试→安全检查→Docker镜像→SWR推送→CCE部署）
- 安全检查：4类规则（SQL注入/XSS/敏感信息/硬编码密钥）+ 高危门禁阻断
- DevLog研发日志 + Insight质量报告 + 实时流水线状态监控面板

### CodeArts生态联动
- Docker化部署（前后端独立容器 + docker-compose本地编排）
- CodeArts Repo代码托管 + 流水线自动触发
- CCE云容器引擎部署（2副本 + 健康检查 + 自动回滚）
- Nginx反向代理统一入口

### 私有知识库与企业规范对齐
- ChromaDB向量数据库持久化存储 + sentence-transformers嵌入
- RAG检索增强：向量搜索 + 关键字降级双模
- 知识库审核流程（上传→待审批→通过/拒绝）+ 审计日志
- 华为云知识湖适配器（降级至本地硬编码字典）
- 前端KnowledgeManager拖拽上传 + RAGReferencePanel相似度评分

### 鸿蒙系统适配
- INearLinkAdapter接口 + WebSocket模拟星闪协议层（API签名与真实SDK对齐，未来可零修改替换）
- NPU正则脱敏（前后端双重：患者ID/手机号/身份证号）
- NpuSandboxPanel可视化沙箱面板 + HarmonyDrawer设备发现/协同 + HarmonyWidget卡片预览
- 响应式CSS布局 + HarmonyOS UA检测 + 断点续传localStorage缓存

### 多模型切换能力
- BaseLLMAdapter基类 + 5大模型适配器（盘古/DeepSeek/OpenAI/GLM/Gemini）
- **盘古真实API适配器**（is_proxy=False，直连华为云，非DeepSeek转发）
- ModelRouterService降级链（pangu→deepseek→openai→glm→gemini）
- 前端ModelSelector + Token监控 + ECharts可视化图表
