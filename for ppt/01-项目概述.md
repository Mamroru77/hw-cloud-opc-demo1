# 云脉 — 项目概述

> 来源：README.md

## 项目定位

**云脉** — 智慧医疗转化医学多智能体工作站

- 大赛场景："华为云杯"2026人工智能OPC应用创新大赛 · 场景五：智慧医疗——"从实验室到临床"的转化医学 Agent
- 核心定位：基于多智能体协同机制的端到端转化医学工作站
- 全链路覆盖：学术论文 → 物理/药理/算法参数提取 → 临床场景适配 → 商业方案生成

## 四大转化医学领域

| 领域 | 代号 | 典型场景 |
|------|------|----------|
| 医疗器械与成像分子 | `devices` | 荧光探针、造影剂、CT/MRI设备 |
| 创新药物与生物治疗 | `drugs` | 靶向小分子、抗体药、基因/细胞治疗 |
| 医疗AI与智能诊断 | `ai` | 医学影像分割、AI辅助筛查(SaMD) |
| 创新临床术式与疗法 | `surgical` | 腹腔镜/胸腔镜微创改良术式 |

## 核心能力矩阵（对标大赛5大技术要求）

### 码道平台特色能力联动
- CI/CD流水线配置 + 安全检查规则
- DevLog研发日志 + 实时流水线状态监控面板 + Insight质量报告

### CodeArts生态联动
- Docker化部署方案 + Nginx反向代理 + CCE云容器引擎部署

### 私有知识库与企业规范对齐
- ChromaDB向量数据库 + RAG检索增强（向量搜索+关键字降级双模）
- 知识库审核流程 + 审计日志 + 华为云知识湖适配器

### 鸿蒙系统适配
- 星闪协议模拟层 + NPU正则脱敏 + HarmonyDrawer/Widget组件
- 响应式CSS布局 + HarmonyOS UA检测 + 断点续传缓存

### 多模型切换能力
- 5大模型适配器（盘古/DeepSeek/OpenAI/GLM/Gemini）+ 盘古真实API直连
- ModelRouterService降级链 + Token监控 + ECharts可视化图表

## 双模降级系统

| 模式 | 条件 | 行为 |
|------|------|------|
| Demo (Mock) | 后端不可达 / 无API Key | 前端内置高保真Mock状态机，数学算法公式渲染 |
| 大模型联调 | 后端运行 + API Key | 全链路LLM推理：论文解析 → 参数提取 → 文档生成 |

RAG服务同样支持降级：ChromaDB不可用时自动退回关键字检索。

## UI视觉体系

采用 **Glassmorphic + Neumorphic** 混合美学：
- 无菌冰灰主色调 + 高斯模糊玻璃面板 + 悬浮拟物阴影
- 四大领域自适应ECharts图表（PK代谢曲线/ROC诊断曲线/学习曲线/雷达图）
