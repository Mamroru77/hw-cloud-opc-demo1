## 核心能力运用

### 9大技术Debug案例
1. **React 19兼容性崩溃**：echarts-for-react依赖废弃的findDOMNode → 手写CustomEChart封装
2. **Vite HMR冲突**：$RefreshSig$未定义 → index.html注入Mock降级机制
3. **ECharts闪烁+打字卡顿**：useMemo状态隔离 + ECharts实例持久化 → 重绘延迟<5ms
4. **双模自动降级**：后端不可达时自动激活前端高保真Mock模式
5. **Flex布局排版拥挤**：white-space:nowrap + ellipsis截断 + gap间距优化
6. **医算子双模接入**：System Prompt交互编辑器 + 全链路上下文自动组装
7. **密钥格式冲突(sk-前缀)**：精准前缀识别 + 手动选择绑定 + 不区分大小写匹配
8. **拖拽上传**：Drag & Drop交互容器 + 正则理化提取 + 哈希参数生成
9. **智能论文领域校验**：LLM学术评审System Prompt + 非相关文件自动拒绝
